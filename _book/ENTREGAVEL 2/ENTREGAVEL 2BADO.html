2  Introdução e interpretação das variáveis: Conhecendo os microdados da PNAD Contínua

2.1 O que são variáveis e por que precisamos interpretá-las?

Antes de iniciar qualquer análise estatística, é necessário compreender quais informações estão disponíveis na base de dados e o que cada uma delas representa.

Uma variável é uma característica observada para cada unidade de análise de uma pesquisa. Na PNAD Contínua, por exemplo, podemos encontrar informações sobre idade, escolaridade, rendimento, condição de ocupação e características dos domicílios.

Em uma pesquisa sobre diferenças de renda entre famílias chefiadas por homens e mulheres, algumas perguntas orientam a escolha das variáveis:

  • Qual é a renda do domicílio?
  • Quem é considerado responsável pelo domicílio?
  • Em qual região do Brasil o domicílio está localizado?
  • Qual é a escolaridade dos moradores?
  • Quantas pessoas compõem o domicílio?

Cada pergunta precisa ser associada a uma ou mais variáveis disponíveis na base de dados.

Uma observação importante: não basta encontrar uma variável com um nome aparentemente adequado. É necessário verificar sua definição, população de referência, período de coleta, categorias de resposta e unidade de medida.

2.2 O que é um dicionário de variáveis?

Um dicionário de variáveis é um documento que descreve as informações presentes em uma base de dados. Ele funciona como um guia para compreender e utilizar corretamente cada variável.

Normalmente, apresenta informações como: Nome da variável, descrição, tipo de variável (numérica, categórica, textual), Categorias (valores ou respostas possíveis), unidade de medida e população de referência

Por exemplo, imagine que uma base apresente a variável V2009. Sem consultar a documentação, o pesquisador não sabe necessariamente o que esse código representa. Ao consultar o dicionário, descobre que se trata de uma informação sobre idade. Essa consulta permite compreender o significado dos dados e evita interpretações equivocadas.

Isso é importante pois:

  • Evita confundir variáveis com nomes ou códigos semelhantes.
  • Permite identificar quais informações são adequadas aos objetivos da pesquisa.
  • Ajuda a reconhecer valores ausentes e categorias especiais.
  • Facilita a interpretação dos resultados.
  • Torna a análise reproduzível por outros pesquisadores.

2.2.1 Como ler um dicionário de variáveis?

Ao abrir o dicionário, você encontrará códigos que identificam as variáveis e suas respectivas descrições.

Código Descrição
V2009 Idade do morador na data de referência
V2007 Sexo do morador
V2005 Condição no domicílio

Para interpretar corretamente essas informações, é necessário observar três elementos:

  1. Código da variável: é o identificador utilizado no banco de dados e nos comandos do R.

  2. Descrição: explica qual característica está sendo investigada.

  3. Categorias ou valores possíveis: indicam como as respostas foram registradas.

Por exemplo, uma variável sobre sexo pode apresentar valores numéricos que representam categorias de resposta. O número não possui significado isoladamente: é a documentação que informa o que cada código representa.

2.3 Tipos de variáveis e unidades de medida

As variáveis podem assumir diferentes formatos, e reconhecer essas diferenças é essencial para escolher os procedimentos estatísticos adequados.

2.3.1 Variáveis qualitativas

Representam características ou categorias. Podem ser divididas em:

  • Nominais: categorias sem uma ordem natural, como sexo, região geográfica e cor ou raça.
  • Ordinais: categorias que apresentam uma ordem, como faixas de escolaridade ou classes de rendimento.

2.3.2 Variáveis quantitativas

Representam valores numéricos e podem ser divididas em:

  • Discretas: assumem valores contáveis, como número de moradores no domicílio.
  • Contínuas: podem assumir diferentes valores dentro de um intervalo, como rendimento mensal.

É importante não confundir o formato numérico de uma variável com seu significado estatístico. Uma variável que utiliza os números 1, 2, 3 e 4 para representar regiões brasileiras continua sendo qualitativa, pois os números são apenas códigos de identificação.

2.3.3 Unidades de medida

Também é necessário identificar a unidade em que cada característica é registrada.

Informação Unidade de medida
Idade Anos
Escolaridade Anos de estudo ou nível de instrução
Rendimento Reais (R$)
Número de moradores Pessoas
Região Categoria geográfica

Essa distinção é especialmente importante na análise de renda. Um rendimento mensal domiciliar total não representa a mesma coisa que um rendimento domiciliar per capita. O primeiro considera a renda total do domicílio; o segundo considera a renda em relação ao número de moradores, conforme a definição específica do indicador.

2.4 Cuidados metodológicos antes de prosseguir

Antes de iniciar as análises, precisamos considerar alguns aspectos importantes.

2.4.1 Unidade de observação

Os microdados da PNAD Contínua apresentam registros individuais dos moradores. Isso significa que um mesmo domicílio pode aparecer em várias linhas, uma para cada morador.

Se o objetivo é comparar rendimentos domiciliares, precisamos tomar cuidado para não contabilizar o mesmo domicílio várias vezes.

2.4.2 Valores ausentes e códigos especiais

Algumas variáveis podem apresentar códigos que representam situações específicas, como informação ignorada ou não aplicável. Esses códigos não devem ser interpretados automaticamente como valores reais.

2.4.3 Rendimentos nominais e reais

Os valores monetários precisam ser interpretados considerando o período de referência. Se o objetivo for comparar rendimentos de diferentes anos, será necessário realizar o deflacionamento.

2.4.4 Pesos amostrais

A PNAD Contínua é uma pesquisa por amostragem probabilística. Portanto, para produzir estimativas representativas da população brasileira, é necessário considerar os pesos amostrais e o desenho da pesquisa. Não basta calcular médias simples dos registros e tratá-las como estimativas populacionais.
